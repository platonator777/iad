# Регрессионный анализ: Crabs и Yacht Hydrodynamics

Основной отчёт — `regression_datasets.ipynb`. Текущая рекомендуемая пара:

- **MASS Crabs:** 200 реальных измерений крабов двух цветовых форм. Общая
  и две отдельные регрессии, разный остаточный разброс, смесь регрессий EM
  со скрытыми метками, несколько предикторов, области совместимости и отказ.
- **UCI Yacht Hydrodynamics:** 308 реальных экспериментальных измерений
  для 22 корпусов. Корень из отклика, B-сплайны всех шести предикторов,
  линейная по коэффициентам Ridge-модель, сравнение на новых корпусах,
  доли вклада факторов, очистка и интервалы.

В выполненном блокноте 21 встроенный график: 8 новых и 13 сохранённых
из предыдущей версии. Код свёрнут, выводы кода содержат только графики;
обоснования и формулы записаны в Markdown. Старые разделы о пингвинах,
Abalone и поиске по прежнему критерию сохранены в явно обозначенном архиве.
Актуальные выводы находятся в начале блокнота.

Crabs и Yacht не встречаются среди 59 названий на четырёх фотографиях
каталога преподавателя. Их список — `data/teacher_dataset_exclusions.json`;
номер 47 на фотографиях не виден. Прямой доступ к GitLab возвращал HTTP 429.

Вклад фактора здесь — доля уменьшения MSE относительно константного прогноза,
рассчитанная по всем 64 подмножествам исходных факторов. Это не процент
«правильных ответов» и не причинное влияние. Отдельно оценено уменьшение
оставшейся после числа Фруда ошибки при добавлении геометрии корпуса.

Ограничения основного анализа: у Crabs нет реальной третьей формы для
проверки неизвестных классов. У Yacht основной порог очистки 3,5 робастных SD
не отмечает строк, порог 3 SD отмечает одну и немного ухудшает тестовую ошибку.
Интервалы приближённые; выбор набора и анализ носят разведочный характер.

## Воспроизведение

Открыть блокнот и выполнить сверху вниз. Использован Python 3.11.
Дублирующий `regression_datasets.py` содержит тот же код и Markdown-комментарии:

```bash
python -m pip install -r requirements.txt
python regression_datasets.py
```

При выполнении пересоздаются:

- `outputs/figures/*.png` — все графики;
- `outputs/analysis_results.json` — все результаты, актуальная часть в `selection_v2`;
- `outputs/selection_v2_results.json` — новые Crabs и Yacht отдельно;
- `outputs/yacht_spline_coefficients.csv` и `outputs/yacht_spline_equation.json` —
  полное уравнение с коэффициентами и узлами B-сплайнов.

Числа в Markdown соответствуют фиксированному запуску с seed=42. При изменении
данных, настроек или схемы разбиения пояснения нужно обновить вместе с графиками.
